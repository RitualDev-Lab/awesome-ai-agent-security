# Contributing to Awesome AI Agent Security

Thank you for your interest in contributing to **Awesome AI Agent Security**!

## Inclusion Guidelines

To maintain high standards for the community:
1. **Direct Relevance**: The project or resource must explicitly address security, sandboxing, isolation, or evaluation of autonomous AI coding agents, tool-calling LLMs, or agentic frameworks.
2. **Active Maintenance**: Open-source tools should have recent commits or releases within the last 12 months.
3. **No Marketing Spam**: Submissions must provide genuine utility to engineers and researchers.
4. **Format Consistency**: Follow the format `[Project Name](link) - Brief description.` in alphabetical order within each category.

## Submission Steps

1. Fork this repository.
2. Create a new branch: `git checkout -b add-my-tool`.
3. Add your tool with a concise one-sentence description.
4. Ensure all Markdown links work and adhere to formatting.
5. Submit a Pull Request with a clear description of why the tool is beneficial.

Thank you for keeping autonomous AI agents secure!
