# Security Policy & Vulnerability Disclosure

RitualDev Lab maintains **awesome-ai-agent-security** as an open community security benchmark and threat taxonomy.

## Reporting a Security Concern

Please **do not** publish live exploit payloads targeting third-party production systems in public issues.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/awesome-ai-agent-security/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY] awesome-ai-agent-security`

## Compliance & Control Alignment

- **Status**: Community Benchmark & OWASP LLM Reference Repository (Self-Attested Control Mapping).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
